A faster drop-in for csv-reader 1.0.0: an exact, dependency-free CSV reader for broken CSV files, built for the make.fun bounty https://make.fun/bounty/csv-reader-speed-01-run-20261121

`solve.js` reads each case's `{text, header}` exactly as csv-reader 1.0.0 does and returns `{columns, rows, errors}`. `main.ts` answers every case in `/input/cases.json` and writes `/output/answers.json`.
